# LexiconGrid

LexiconGrid is a hyper-meta data platform that facilitates map-based aggregated data curation through a centralized data manager service.

With LexiconGrid, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/LexiconGrid.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
